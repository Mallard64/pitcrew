OmniSTEM is a gamified AP Chemistry web app: Duolingo-style lessons with hearts, XP and streaks, a daily equation-balancing challenge, friends, and an item store.

Problem: AP Chemistry practice can mean rereading a textbook chapter with no quick way to check yourself. OmniSTEM turns Unit 1 into short lessons with immediate feedback.

How it works: 8 College Board CED learning objectives from Unit 1, four question types (multiple choice, multi-select, ordering, fill-in), and a daily balance-the-equation puzzle with a timer and scoring. Questions are generated by GPT-4o per objective, validated against a zod schema, retried up to 3 times on invalid output, and fall back to a hand-written seed bank. A Zustand store mirrors to Supabase (Postgres and Auth, with RLS) when configured and to localStorage when not. Dark mode and English/Spanish UI strings are included. In the repo's eval of 24 questions across 8 topics, schema validity, answer-key integrity and on-objective rates were 100%, uniqueness was 96% and answer correctness was 96%.

Stack: Next.js 14 (App Router), TypeScript, Tailwind, Zustand, Supabase, OpenAI GPT-4o, zod.

Status and limits: not deployed yet. Only Unit 1 of the CED is covered, and there is no offline service worker. In local-only mode the friends list and daily leaderboard are seeded demo data.
