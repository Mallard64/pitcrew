- 2026-11-17 14:20 PT, **Video structure:** problem (~10–15s) → solution with animated how-it-works diagram (~10–15s) → demo (~30–45s) → what's next (~8–12s, omitted without a real source) → end card with URL + "Made with Pit Crew". - 2026-11-17 14:20 PT, **Rendering moves to Remotion** (React → mp4); the ffmpeg assembler becomes the emergency fallback (with the slideshow, C4). The agent outputs a video-plan JSON using a fixed vocabulary (primitives, layouts per section, motion presets, transitions, 6–8 style kits, seeded variation) and never writes SVG/CSS. A zod validator enforces readability, contrast (WCAG AA), timing and transition variety, and the agent revises on failure. Why: per-project variety without breaking quality, and reproducibility from the seed. Alternatives: fixed templates (samey), agent-written SVG/CSS (fragile).
- 2026-11-17 14:20 PT, **Remotion license:** Remotion is source-available, not OSI open source. As we understand its license, it's free for individuals, non-profits and companies with up to 3 employees; larger companies need a paid company license. A student hackathon team qualifies for free use. Re-check https://www.remotion.dev/license before any commercial launch or if the team/company grows. Alternatives considered: plain ffmpeg (no text rendering in many builds, limited motion), Motion Canvas (smaller ecosystem).
- 2026-11-17 14:20 PT, Diagrams use auto-layout (elkjs; radial for hub-and-spoke) from agent-provided nodes/edges/groups, animated in sync with the narration's word timings. Why: hand-placed coordinates from an LLM overlap and drift.
- 2026-11-17 14:20 PT, **Self-review pass:** after rendering, sampled frames go back to the agent in the same HarnessRouter session (`previous_response_id`); it fixes the worst issue once, then ships. Why: catches the issues we've only found by looking at frames (e.g. the unstyled title card), capped at one fix to protect the time budget.

Phase 0 decides agent-side vs server-side search (C19). Eval criterion: 0 unverified stats. Why: one wrong number in a judged pitch costs more than no number.
