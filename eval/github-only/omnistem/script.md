# OmniSTEM: pitch script

**problem** (big-statement): You've reread the moles chapter twice, and you still can't tell if it stuck. A textbook never quizzes you back.

**solution** (big-statement): OmniSTEM fixes that: a Duolingo-style AP Chemistry app with short lessons, hearts, XP, streaks, and a daily equation-balancing puzzle.

**demo** (full-frame): On the landing page, a student sees bite-size AP Chemistry lessons, a daily equation-balancing puzzle, and a streak to keep.

**demo** (full-frame): The welcome screen sets expectations: daily two-minute lessons and a puzzle, so practice stays short.

**demo** (full-frame): Get started asks one question, what brings you here, with AP Chem, high school chem, or just exploring as choices.

**demo** (framed-zoom): Clicking AP Chem outlines the card in red and enables Continue, so the app can match its tone to the student.

**built** (diagram): It's built on Next.js, with a Zustand store that syncs to Supabase, or to local storage without it. GPT-4o writes the questions, zod checks them, and a seed bank is the fallback.

**ask** (big-statement): Try it at github.com/Mallard64/stemduolingo.

**end** (end-card): _(no narration)_
