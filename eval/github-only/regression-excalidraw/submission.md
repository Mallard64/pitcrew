## Excalidraw

**What it is:** Excalidraw is an open source virtual whiteboard for sketching hand-drawn style diagrams. It is collaborative and end-to-end encrypted, and the editor is also published as an npm package (@excalidraw/excalidraw).

**Problem:** Getting a rough idea in front of someone should not require an account, a template or polished tooling. People want a blank canvas they can sketch on immediately.

**How it works:** The app at excalidraw.com opens straight to an infinite canvas with a toolbar of shapes, arrows, lines, free-draw, text, sticky notes and an eraser. Drawings autosave in the browser, work offline as a PWA, and can be exported to PNG, SVG, the clipboard or an open .excalidraw JSON file. Real-time collaboration and shareable links are built in. The repo is a TypeScript monorepo with the editor package, the excalidraw-app and examples.
