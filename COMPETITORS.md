## How we're different
**"Others record a walkthrough. Pit Crew makes your pitch."**
1. **Narrative pitch, not a click-through.** Problem → solution → demo → what's next, built from the live site, README, commits and issues, so the video explains *why*, not just *where to click*.
2. **A complete hackathon submission kit from one run:** pitch video + build log + submission text.
3. **Agent-directed editing.** The agent picks the style kit, layouts, motion and transitions per project from a design vocabulary, so no two videos look the same, and a validator keeps every one readable.
4. **Runs on HarnessRouter** with multi-harness cost routing (a strong model directs; a cheaper one writes the build log and submission text).

Auto-update-on-release is the category the last table already covers. For us it's a P2 nice-to-have, not the expansion story.
