# Excalidraw: pitch script

**problem** (big-statement): A teammate is waiting for your idea. You open a diagramming tool and it asks you to sign up first. You only wanted a blank canvas.

**solution** (big-statement): Excalidraw is an open source whiteboard that turns rough sketches into hand-drawn style diagrams, with no sign-up in the way.

**demo** (full-frame): Open excalidraw.com and the canvas is already blank. No sign-up screen, no setup, just a toolbar.

**demo** (framed-zoom): Choose the text tool. Rectangles, arrows, sticky notes and an eraser sit right beside it.

**demo** (full-frame): Click anywhere on the canvas. A text cursor appears right where you clicked, ready for your first word.

**demo** (framed-zoom): Type a line and it lands on the canvas in a hand-drawn font. Your drawing autosaves in the browser.

**evidence** (bullet-reveal): The open source repo has 135,932 GitHub stars. 381 contributors have helped build it.

**ask** (big-statement): Try it at excalidraw.com.

**end** (end-card): _(no narration)_
